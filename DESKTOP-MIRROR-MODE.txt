NEXARVIA V52 — DESKTOP-TO-MOBILE MIRROR MODE

Desktop design width: 1440px

Every HTML page now uses:
- Fixed 1440px layout viewport
- Full-page desktop canvas wrapper
- Proportional transform scaling on narrower devices
- Desktop media-query layout preservation
- No page-level horizontal scrolling
- Dynamic scaled-height correction
- Orientation, font, image, animation and content-change recalculation

Existing website content, forms, Firebase settings, Google Sheets endpoints,
animations, Home navigation, Student Login, LMS preview and Admin Portal
flows were preserved from V51.

Important usability note:
This mode intentionally scales desktop typography, buttons and form controls
on mobile instead of reflowing them. Users can still pinch-zoom for closer
inspection because browser zoom has not been disabled.
