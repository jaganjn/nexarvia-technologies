Nexarvia V49 — Learning Journey Number Visibility Fix

Cause:
The active circle used background: currentColor after the number colour changed to white. This made the circle and number white, hiding the stage number during transitions.

Fix:
- Added a dedicated --step-color variable for each stage.
- Active circle now uses the stage accent as its background and white only for the number text.
- Forced number visibility and opacity throughout active/transition states.
- Added a subtle pulse ring below the number without covering it.
- Updated cache query to v49.

No Learning application, Firebase, referral, or Google Sheets logic was changed.
