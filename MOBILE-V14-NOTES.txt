SkillPath V14 Mobile Parity Update

Landing page fixes:
- Application wizard now fits 320px-820px screens without clipped step labels or horizontal overflow.
- All inputs use mobile-safe sizing and full-width controls.
- Header Apply button, full footer information, form review, consent and success sections remain visible.
- Decorative and content sections are retained and stacked for mobile rather than removed.

Admin dashboard fixes:
- All desktop navigation destinations are now present in the fixed two-row mobile navigation.
- The full sidebar is still available through Full Menu or the top hamburger.
- Firebase status, sound toggle, clock, portal button and system health remain visible on mobile.
- Dashboard panels, referral sections, controls and settings are retained.
- Large referral tables are horizontally scrollable instead of being clipped.
- Added safe spacing so the two-row mobile navigation does not cover content.

No Firebase database paths or application/referral logic were changed in this mobile-only release.
