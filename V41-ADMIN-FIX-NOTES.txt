Nexarvia Technologies V41 — Mobile Admin Content & Motion Fix

Critical mobile fix
- V40 used workspace.children, which returned <main>, footer, nav and notification drawer.
- The screen controller hid the complete <main>, then attempted to reveal descendants inside it.
- V41 switches only direct children of .workspace > main.
- The <main> container remains visible at all times.

Navigation fixes
- Removed the duplicate dynamically-created hamburger and overlay.
- Uses the existing #menuToggle, #sidebar and #mobileOverlay controlled by admin.js.
- Rebuilt the existing bottom navigation into five reliable screen controls.
- Dashboard, Applications, Enquiries and Referrals display as separate mobile states.
- More opens the complete secure admin drawer.

Motion restoration
- Removed the V40 transform:none!important rule that cancelled admin movement.
- Added admin-motion-v41.css and admin-motion-v41.js.
- Includes hero light sweep, live-status pulse, metric icon float, count update pulse,
  chart growth, data arrival, drawer-link stagger and mobile screen transitions.
- Content remains visible by default if JavaScript or Firebase is delayed.
- Reduced-motion accessibility is supported.
