CONFIGURE OFFICIAL SOCIAL LINKS
Open site-config.js and paste only your verified official URLs:

window.NEXARVIA_SITE_CONFIG = {
  supportEmail: "",
  social: {
    linkedin: "https://...",
    instagram: "https://...",
    youtube: "https://...",
    facebook: "https://...",
    whatsapp: "https://wa.me/..."
  }
};

Links left empty are intentionally disabled so the website never sends students to an unofficial or incorrect page.
