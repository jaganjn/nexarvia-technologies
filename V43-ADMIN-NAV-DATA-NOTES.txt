Nexarvia V43 — Common Admin Navigation & Safe Data Controls

1. The admin topbar now returns to Corporate Home instead of Nexarvia Learning.
2. Mobile header grid widths were corrected so Firebase status, clock, notification and Home controls do not clip.
3. The mobile More menu includes Corporate Home and a protected Clear All Data action.
4. Clear All Current Data requires typing DELETE ALL DATA before execution.
5. The clear action removes current live visitors, Learning applications, Technology Services enquiries, referral records and website announcements. It does not delete administrator accounts or website files.
6. Deletion operates on permitted child records, matching the included path-specific Firebase rules.
7. Existing individual delete controls were corrected to use the same rule-compatible deletion method.
8. Mobile bottom navigation moves away while a form field is focused and extra bottom spacing prevents controls from being covered.
