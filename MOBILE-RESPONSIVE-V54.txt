Nexarvia Technologies V54 — Readable Mobile Experience

This release replaces the fixed 1440px mobile mirror with a responsive,
desktop-inspired mobile layout.

Included:
- Standard device viewport on all pages
- Larger mobile header, logo, navigation and touch controls
- Readable mobile typography and buttons
- Stable navigation drawer through tablet widths
- Responsive single-column forms
- Intentional horizontal swipe only for selected visual card journeys
- Existing desktop layouts, animations, application logic, Firebase settings,
  Google Sheets configuration, LMS pages and admin flows preserved
